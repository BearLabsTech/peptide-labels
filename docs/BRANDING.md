# Branding and marketing ideas

Parking lot for product naming, slogans, positioning, and related marketing notes. **Not** a commitment to ship any of these — when a name or line is chosen, update the product, [FRD.md](./FRD.md), and [COPY-GUIDELINES.md](./COPY-GUIDELINES.md) as needed.

Anything that becomes user-facing must still pass research-use / non-clinical framing in COPY-GUIDELINES and the user agreement.
